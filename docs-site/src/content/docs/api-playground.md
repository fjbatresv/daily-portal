---
title: API Playground
description: Playground para probar endpoints del backend usando el contrato OpenAPI.
---

El playground usa el mismo `openapi.yaml` publicado por el sitio. La URL base se puede cambiar desde la barra superior del visor para apuntar a NestJS local, Docker en `8090` o el dominio expuesto por Cloudflare Tunnel.

[Abrir API Playground](../reference/api-playground/)

Valores comunes:

- `http://localhost:3000`
- `http://localhost:8090/api`
- `https://TU-DOMINIO.example.com/api`
